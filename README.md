# Git 工作坊 — 活動網站

這是 Git 工作坊的活動網站專案，用來練習團隊協作流程。

## 專案結構

```
├── index.html      首頁
├── schedule.html    課程時間表
├── faq.html         常見問題
├── style.css        共用樣式
└── README.md
```

## 開發流程

1. 從 `dev` 分支建立功能分支
2. 完成修改後推上 GitHub
3. 開 PR 到 `dev`，請同伴 Review
4. 通過後合併

## 本地開發

直接用瀏覽器打開 `index.html` 即可預覽。
